
# 能量计算模块设计指导

请结合当前工程，实现独立的基波与谐波能量计算模块，建议文件名：

```text
energy_calculator.sv
```

模块统一使用 SystemVerilog 编写。

## 当前实现状态

第一版 RTL 已实现于：

```text
fpga/src/hdl/energy_calculator.sv
```

配套自检式测试为：

```text
fpga/src/sim/energy_calculator_tb.sv
fpga/src/sim/energy_calculator_overflow_tb.sv
```

当前实现使用一套状态机依次处理三个候选频率。为了满足100 MHz时序，
`candidate_bin` 的除以125采用40拍逐位无符号除法，比例乘法与比较也拆分为
独立状态。每个候选频率仍支持连续提交7个频谱读取请求。

当前行为仿真、自检式溢出测试和OOC综合均已通过；xc7z020clg400-2综合后
100 MHz时序余量 WNS 为2.155 ns。

请遵循现有工程规范：

* 模块顶部使用中文注释说明功能、使用方法、接口连接方式、输入输出格式和时序要求；
* 每个输入、输出端口均添加中文注释；
* 参数和信号命名简洁清晰；
* 不在模块内部自行分频，时钟由统一时钟树提供；
* 使用一套可复用状态机依次处理三个候选频率，不复制三套相似逻辑；
* 编写对应 testbench，验证读取握手、能量累加、谐波判断、缩放和 BRAM 写入过程；
* 在模块和测试文件底部，用中文注释记录实现过程中发现的问题以及解决方法。

## 一、模块功能

能量计算模块负责根据基频检测结果，生成一帧完整的基波与谐波能量分析结果。

模块完成以下工作：

1. 接收基频检测模块输出的 `base_index_500`；
2. 计算三个候选频率：

   * 基波 (f_0)；
   * 二次谐波 (2f_0)；
   * 三次谐波 (3f_0)；
3. 将三个候选频率转换为频谱 BRAM 中的 FFT 下标；
4. 通过 Spectrol 提供的读取接口访问频谱 BRAM；
5. 对每个候选频率中心附近的 7 根功率谱线求和；
6. 判断二次谐波和三次谐波是否真实存在；
7. 将三个候选频率的 `index_500` 和能量写入独立的能量结果 BRAM；
8. 将谐波存在情况和候选位置有效情况打包进一个 32 位状态字；
9. 所有结果写完后，最后置位 `result_valid`；
10. 产生一个时钟周期的 `done` 信号。

能量计算、谐波判断和结果 BRAM 写入由同一个模块完成。

当前系统最多包含：

```text
1个基波 + 2个高次谐波
```

因此只需要处理基波、二次谐波和三次谐波三个候选位置。

## 二、基频输入格式

基频检测模块提供：

```verilog
input             base_valid;
input      [15:0] base_index_500;
```

频率定义为：

```text
frequency_hz = index_500 × 500 Hz
```

例如：

```text
base_index_500 = 2
```

表示：

```text
基频 = 2 × 500 Hz = 1000 Hz
```

又例如：

```text
base_index_500 = 10
```

表示：

```text
基频 = 10 × 500 Hz = 5 kHz
```

三个候选频率编号分别为：

```text
基波：      candidate_index_500 = 1 × base_index_500
二次谐波：  candidate_index_500 = 2 × base_index_500
三次谐波：  candidate_index_500 = 3 × base_index_500
```

需要使用足够宽的中间变量保存乘法结果，不能让结果在边界检查前发生截断或溢出。

---

## 三、FFT 下标计算

结果 BRAM 中保存的是 `index_500`，不保存 FFT bin。

FFT bin 只在模块内部使用，用于生成频谱 BRAM 的读取地址。

当前 FFT 频率间隔为：

```text
488.28125 Hz
```

候选频率对应的 FFT 下标为：

```text
candidate_bin =
    (128 × candidate_index_500 + 62) ÷ 125
```

其中：

* 除法为整数除法；
* 加 62 用于近似四舍五入。

不要使用：

```text
candidate_bin = candidate_order × rounded_base_bin
```

因为基波 FFT 下标已经经过取整，再进行倍乘会使高次谐波的位置误差累积。

频率换算相关常量应集中定义或参数化，避免在状态机内部散布魔法数字。

---

## 四、候选频率范围检查

当前频谱 BRAM 保存正频率部分，最大有效 FFT 下标暂定为：

```verilog
parameter MAX_SPECTRUM_BIN = 2047;
```

每个候选频率需要读取中心附近 7 根谱线，因此中心位置必须满足：

```text
candidate_bin >= 3
candidate_bin + 3 <= MAX_SPECTRUM_BIN
```

建议定义：

```verilog
parameter WINDOW_RADIUS = 3;
```

读取点数为：

```text
WINDOW_POINTS = 2 × WINDOW_RADIUS + 1
```

当前：

```text
WINDOW_POINTS = 7
```

如果某个候选频率的完整窗口超出频谱范围：

1. 不发起对应的频谱读取；
2. 对应内部能量和输出能量均记为 0；
3. 对应 `index_500` 仍然写入结果 BRAM；
4. 将对应的位置有效位清零；
5. 该候选频率不能被判定为真实存在。

---

## 五、能量计算方法

每个候选频率的内部能量定义为中心附近 7 根功率谱线之和：

```text
energy =
    P[center_bin - 3]
  + P[center_bin - 2]
  + P[center_bin - 1]
  + P[center_bin]
  + P[center_bin + 1]
  + P[center_bin + 2]
  + P[center_bin + 3]
```

其中 `P[k]` 为频谱 BRAM 中保存的功率谱数据。

模块输出不要求直接表示经过物理单位标定的绝对能量，但应尽量保持比例关系。

对于相同频率、相同测量链路的正弦波，如果输入幅值由：

```text
A
```

变为：

```text
2A
```

则功率和能量应近似满足：

```text
E → 4E
```

因此，三个候选频率和所有测量帧必须使用相同的：

* 功率谱格式；
* 7 点累加规则；
* 缩放位数；
* 四舍五入规则；
* 32 位输出规则。

不能为不同频率或不同帧单独改变缩放比例。

## 六、频谱读取接口

能量模块不直接控制频谱 BRAM，而是通过 Spectrol 的统一读取接口访问：

```verilog
output reg                    mem_req;
output reg  [10:0]            mem_addr;
input                         mem_ready;
input                         mem_rvalid;
input       [POWER_WIDTH-1:0] mem_rdata;
```

一次读取请求成功提交的条件为：

```text
mem_req && mem_ready
```

只有在：

```text
mem_rvalid == 1
```

时，才能将 `mem_rdata` 加入能量累加器。

模块不能依赖固定的 BRAM 读取延迟，应完全依据 `mem_rvalid` 接收返回数据。

需要分别维护：

```text
issue_count
receive_count
```

其中：

* `issue_count`：已经被 Spectrol 接受的读取请求数量；
* `receive_count`：已经收到的有效返回数据数量。

必须支持同一周期内同时发生：

```text
mem_req && mem_ready
```

和：

```text
mem_rvalid
```

即提交新请求和接收旧请求返回数据可以同时发生。

只有收到完整的 7 个有效返回数据后，当前候选频率的能量才真正完成。

特别注意收到第 7 个数据时的非阻塞赋值问题。

不能直接写成类似：

```verilog
energy_acc <= energy_acc + mem_rdata;
saved_energy <= energy_acc;
```

因为 `saved_energy` 得到的是旧的 `energy_acc`，不包含最后一个 `mem_rdata`。

应先形成包含当前返回数据的完整和，再保存最终能量。

---

## 七、内部累加位宽

如果单根功率谱数据宽度为：

```verilog
parameter POWER_WIDTH = 32;
```

7 点累加至少需要额外 3 位：

```verilog
parameter ENERGY_ACC_WIDTH = POWER_WIDTH + 3;
```

因此当前固定配置下：

```text
POWER_WIDTH      = 32 bit
ENERGY_ACC_WIDTH = 35 bit
```

`mem_rdata` 是功率计算模块完成固定缩放、四舍五入和 32 位处理后写入频谱
BRAM 的无符号功率值。

建议分别保存三个未缩放能量：

```verilog
reg [ENERGY_ACC_WIDTH-1:0] base_energy_raw;
reg [ENERGY_ACC_WIDTH-1:0] harmonic2_energy_raw;
reg [ENERGY_ACC_WIDTH-1:0] harmonic3_energy_raw;
```

谐波存在判断使用右移前的内部宽位能量，避免弱谐波经过缩放后损失过多精度。

---

## 八、固定右移和四舍五入

能量写入结果 BRAM 前，统一右移 3 位：

```verilog
parameter integer ENERGY_SHIFT = 3;
```

也就是所有能量统一除以：

```text
2^3 = 8
```

当前单根功率谱线为 U32，7 根谱线的最坏情况累加值满足：

```text
7 × (2^32 - 1) < 2^35
```

因此内部使用 35 位累加器，再固定右移 3 位，可以保证任意 7 个合法 U32
功率值的累计结果均能放入 U32。饱和逻辑仍保留为防御性保护。

禁止根据：

* 当前输入幅值；
* 当前候选频率；
* 当前测量帧；
* 当前最大能量；

动态调整右移位数。

所有结果都使用固定的：

```text
ENERGY_SHIFT = 3
```

这样后续统一标定后，测量其他信号时不需要重新调整缩放规则。

### 1. 不使用直接截断

不要简单写成：

```verilog
energy_scaled = energy_raw >> 3;
```

这种方式会直接丢弃低 3 位，相当于始终向下取整。

### 2. 使用四舍五入

右移前先加：

```text
2^(3-1) = 4
```

因此缩放公式为：

```text
energy_scaled = (energy_raw + 4) >> 3
```

数学意义为：

```text
energy_scaled = round(energy_raw ÷ 8)
```

三个候选频率必须使用相同规则：

```text
base_energy_out
    = round(base_energy_raw ÷ 8)

harmonic2_energy_out
    = round(harmonic2_energy_raw ÷ 8)

harmonic3_energy_out
    = round(harmonic3_energy_raw ÷ 8)
```

加 4 前需要先将原始能量扩展一位，防止加法进位溢出。

概念实现如下：

```verilog
wire [ENERGY_ACC_WIDTH:0] energy_rounded;
wire [ENERGY_ACC_WIDTH:0] energy_scaled_full;

assign energy_rounded =
    {1'b0, energy_raw} + 3'd4;

assign energy_scaled_full =
    energy_rounded >> ENERGY_SHIFT;
```

具体写法需要确保常量位宽和拼接位宽符合 SystemVerilog 规则。

## 九、32 位能量输出

结果 BRAM 中每个能量字段固定为 32 位。

缩放后，如果高于 bit 31 的位置全部为 0：

```text
energy_out = energy_scaled_full[31:0]
```

如果缩放后仍然超出 32 位：

```text
energy_out = 32'hFFFF_FFFF
energy_overflow = 1
```

饱和只作为异常保护，不作为正常的数据缩放方式。

正常情况下，通过固定右移 3 位，任意 7 个合法 U32 功率值的累计结果均不应
发生饱和。

如果出现 `energy_overflow`，可能表示：

* 输入超过设计范围；
* FFT 或功率谱缩放方式发生变化；
* 功率谱位宽发生变化；
* 固定右移 3 位不足；
* 内部位宽估计错误。

发生溢出的结果仍然可以写入 BRAM，但 PS 应根据状态字判断该结果存在异常。

## 十、谐波存在判断

基波在以下条件满足时默认有效：

```text
base_valid == 1
```

并且：

```text
基波7点窗口位于有效频谱范围内
```

二次谐波和三次谐波需要根据能量判断是否真实存在。

建议同时保留：

1. 绝对能量阈值；
2. 相对于基波能量的比例阈值。

判断逻辑为：

```text
harmonic_present =
    position_valid
    && harmonic_energy_raw >= absolute_threshold
    && harmonic_energy_raw × ratio_den
       >= base_energy_raw × ratio_num
```

例如：

```text
ratio_num = 1
ratio_den = 100
```

表示候选谐波能量至少达到基波能量的 1%。

谐波判断应使用右移前的 `raw` 能量。

比例比较时，两个乘法结果必须使用足够宽的中间变量，避免乘法结果溢出。

需要处理：

```text
ratio_den == 0
```

如果比例分母为 0：

* 设置 `threshold_invalid`；
* 二次和三次谐波不能被判定为存在。

建议接口为：

```verilog
input      [31:0] absolute_threshold;
input      [15:0] ratio_num;
input      [15:0] ratio_den;
```

绝对阈值在比较时扩展到 `ENERGY_ACC_WIDTH`。

`absolute_threshold` 的数值尺度固定定义为：

```text
FFT功率已经完成POWER_SHIFT=8
→ 7根U32功率谱线完成求和
→ 尚未执行ENERGY_SHIFT=3
```

也就是说，绝对阈值直接与右移前的 `energy_raw` 比较，不使用最终写入结果
BRAM的32位缩放能量尺度。PS配置阈值时必须使用这一原始7点能量尺度。

如果现有参数 BRAM 使用其他位宽或字段格式，应结合工程实际调整。

## 十一、内部掩码

模块内部可以保留两个 3 位寄存器，以方便状态机处理。

### 1. 候选位置有效掩码

```verilog
reg [2:0] position_valid_mask;
```

定义为：

```text
bit 0：基波7点窗口位于有效频谱范围
bit 1：二次谐波7点窗口位于有效频谱范围
bit 2：三次谐波7点窗口位于有效频谱范围
```

### 2. 基波与谐波存在掩码

```verilog
reg [2:0] harmonic_present_mask;
```

定义为：

```text
bit 0：基波有效
bit 1：二次谐波真实存在
bit 2：三次谐波真实存在
```

例如：

```text
3'b001
```

表示只有基波。

```text
3'b011
```

表示基波和二次谐波存在。

```text
3'b101
```

表示基波和三次谐波存在。

```text
3'b111
```

表示基波、二次谐波和三次谐波均存在。

不再生成或保存 `result_count`。

PS 如果需要知道有效结果数量，可以自行统计 `harmonic_present_mask` 中置 1 的位数。

位置有效和谐波存在不是相同概念：

* `position_valid = 0`：该候选频率已经超出可读取频谱范围；
* `position_valid = 1`、`harmonic_present = 0`：该位置已经计算，但能量低于判定阈值。

两个掩码最终统一打包进地址 0 的状态字，不再分别占用 BRAM 地址。

## 十二、能量结果 BRAM

使用一块独立的双口 BRAM 保存结果：

```text
Port A：能量计算模块写入
Port B：PS通过AXI读取
```

推荐配置：

```text
数据宽度：32 bit
深度：至少16个32位字
```

当前有效字段只使用前 10 个字，额外深度用于后续扩展。

模块负责 Port A：

```verilog
output reg                         result_bram_en;
output reg                         result_bram_we;
output reg [RESULT_ADDR_WIDTH-1:0] result_bram_addr;
output reg [31:0]                  result_bram_din;
```

如果 Block Memory Generator 的写使能为向量形式，应在顶层或封装层适配，不要让能量模块依赖具体 BRAM IP 的端口命名。

## 十三、修改后的结果 BRAM 布局

能量结果 BRAM 固定使用以下 32 位字布局：

| 字地址 | 字段                    | 说明                             |
| -----: | ----------------------- | -------------------------------- |
|      0 | `status_word`         | 状态、谐波存在掩码和位置有效掩码 |
|      1 | `base_index_500`      | 基波频率编号                     |
|      2 | `base_energy`         | 基波缩放后能量                   |
|      3 | `harmonic2_index_500` | 二次谐波频率编号                 |
|      4 | `harmonic2_energy`    | 二次谐波缩放后能量               |
|      5 | `harmonic3_index_500` | 三次谐波频率编号                 |
|      6 | `harmonic3_energy`    | 三次谐波缩放后能量               |
|      7 | `energy_shift`        | 固定写入`32'd3`                |
|      8 | `absolute_threshold`  | 本次使用的绝对能量阈值           |
|      9 | `ratio_parameter`     | 比例参数打包结果                 |
| 10～15 | 保留                    | 每帧显式写0，供后续扩展          |

已删除以下字段：

```text
harmonic_valid_mask 独立地址
position_valid_mask 独立地址
result_count
frame_id
```

两个掩码统一放入地址 0 的状态字中。

### 频率字段格式

频率字段保存 32 位 `index_500`。

例如地址 1 保存：

```text
10
```

表示基波频率为：

```text
10 × 500 Hz = 5 kHz
```

内部用于读取频谱的 FFT bin 不写入结果 BRAM。

### 比例参数格式

地址 9 可以打包为：

```text
bit 15:0  ：ratio_num
bit 31:16 ：ratio_den
```

对应写入形式：

```verilog
result_bram_din <= {ratio_den, ratio_num};
```

## 十四、状态字定义

地址 0 为一个 32 位状态字。

推荐定义如下：

|    位 | 名称                         | 含义                             |
| ----: | ---------------------------- | -------------------------------- |
|     0 | `result_valid`             | 当前 BRAM 中已经保存完整的新结果 |
|     1 | `busy`                     | 能量模块正在处理                 |
|     2 | `energy_overflow`          | 至少一个32位能量发生异常饱和     |
|     3 | `base_invalid`             | 基频输入无效或基波窗口越界       |
|     4 | `threshold_invalid`        | 谐波判断参数无效                 |
|     5 | `read_error`               | 频谱读取异常，当前可保留         |
|   7:6 | 保留                         | 写0                              |
|     8 | `base_present`             | 基波存在                         |
|     9 | `harmonic2_present`        | 二次谐波存在                     |
|    10 | `harmonic3_present`        | 三次谐波存在                     |
|    11 | `base_position_valid`      | 基波7点窗口有效                  |
|    12 | `harmonic2_position_valid` | 二次谐波7点窗口有效              |
|    13 | `harmonic3_position_valid` | 三次谐波7点窗口有效              |
| 31:14 | 保留                         | 写0                              |

其中：

```text
status_word[10:8]
```

表示哪些基波或谐波真实存在。

```text
status_word[13:11]
```

表示哪些候选频率位于可读取频谱范围内。

推荐在代码中逐位构造状态字，避免长拼接造成位顺序错误：

```verilog
status_word = 32'd0;

status_word[0]     = result_valid;
status_word[1]     = busy;
status_word[2]     = energy_overflow;
status_word[3]     = base_invalid;
status_word[4]     = threshold_invalid;
status_word[5]     = read_error;

status_word[10:8]  = harmonic_present_mask;
status_word[13:11] = position_valid_mask;
```

### 新一帧开始时

首先写地址 0：

```text
result_valid = 0
busy = 1
```

同时清除上一帧的：

* 谐波存在掩码；
* 位置有效掩码；
* 溢出状态；
* 参数错误状态；
* 读取错误状态。

### 所有结果完成后

最后再次写地址 0：

```text
busy = 0
result_valid = 1
```

地址 0 的最终状态字必须是整帧最后一次 BRAM 写操作。

这样 PS 只有在看到：

```text
status_word[0] == 1
```

时，才读取地址 1～9 的结果。

## 十五、推荐状态机

使用一个候选次序寄存器：

```verilog
candidate_order
```

依次取值：

```text
1：基波
2：二次谐波
3：三次谐波
```

复用同一套地址计算、频谱读取和能量累加逻辑。

推荐状态流程：

```text
IDLE
  ↓
INIT
  ↓
WRITE_BUSY_STATUS
  ↓
PREPARE_CANDIDATE
  ↓
CHECK_POSITION
  ├─位置无效 → SAVE_ZERO
  └─位置有效
          ↓
    READ_SPECTRUM
          ↓
    SAVE_RAW_ENERGY
          ↓
NEXT_CANDIDATE
  ├─还有候选频率 → PREPARE_CANDIDATE
  └─三个候选均完成
          ↓
CHECK_HARMONICS
          ↓
SCALE_AND_ROUND
          ↓
WRITE_RESULT_WORDS
          ↓
WRITE_FINAL_STATUS
          ↓
DONE
          ↓
IDLE
```

推荐状态定义可参考：

```verilog
localparam STATE_IDLE            = 4'd0;
localparam STATE_INIT            = 4'd1;
localparam STATE_WRITE_BUSY      = 4'd2;
localparam STATE_PREPARE         = 4'd3;
localparam STATE_READ            = 4'd4;
localparam STATE_SAVE_ENERGY     = 4'd5;
localparam STATE_NEXT            = 4'd6;
localparam STATE_CHECK_HARMONICS = 4'd7;
localparam STATE_SCALE_ENERGY    = 4'd8;
localparam STATE_WRITE_RESULTS   = 4'd9;
localparam STATE_COMMIT          = 4'd10;
localparam STATE_DONE            = 4'd11;
```

状态名称和数量可以结合实际实现调整，不要求机械照抄。

`STATE_READ` 中需要同时处理：

```text
mem_req && mem_ready
```

和：

```text
mem_rvalid
```

结果 BRAM 写入阶段依次写入地址 1～15，其中地址 10～15 每帧显式写 0，
最后单独写地址 0。

## 十六、推荐接口框架

以下接口仅作为参考，应结合现有 Spectrol、参数 BRAM 和结果 BRAM 接口调整：

```verilog
module energy_calculator #(
    parameter POWER_WIDTH          = 32,
    parameter ENERGY_ACC_WIDTH     = POWER_WIDTH + 3,
    parameter ENERGY_SHIFT         = 3,
    parameter INDEX_WIDTH          = 16,
    parameter SPECTRUM_ADDR_WIDTH  = 11,
    parameter RESULT_ADDR_WIDTH    = 4,
    parameter WINDOW_RADIUS        = 3,
    parameter MAX_SPECTRUM_BIN     = 2047
)(
    input                                clk,
    input                                rst,

    // 控制与基频输入
    input                                start,
    input                                base_valid,
    input      [INDEX_WIDTH-1:0]         base_index_500,

    // 谐波判断参数
    input      [31:0]                    absolute_threshold,
    input      [15:0]                    ratio_num,
    input      [15:0]                    ratio_den,

    // 模块状态
    output reg                           busy,
    output reg                           done,

    // 通过Spectrol读取频谱BRAM
    output reg                           mem_req,
    output reg [SPECTRUM_ADDR_WIDTH-1:0] mem_addr,
    input                                mem_ready,
    input                                mem_rvalid,
    input      [POWER_WIDTH-1:0]         mem_rdata,

    // 能量结果BRAM写端口
    output reg                           result_bram_en,
    output reg                           result_bram_we,
    output reg [RESULT_ADDR_WIDTH-1:0]   result_bram_addr,
    output reg [31:0]                    result_bram_din,

    // 可选调试输出
    output reg [2:0]                     harmonic_present_mask,
    output reg [2:0]                     position_valid_mask,
    output reg                           result_valid,
    output reg                           energy_overflow
);
```

这里的掩码输出仅用于顶层观察或 ILA 调试。

PS 不直接依赖这些普通 PL 信号，而是读取结果 BRAM 地址 0 中打包后的状态字。

`done` 在最终状态字写入完成后拉高一个时钟周期。

当 `busy == 1` 时再次收到 `start`，默认忽略新的启动请求。

即使 `base_valid == 0`，Spectrol也必须启动本模块。本模块不读取频谱，将三个
候选能量写为0，提交带有 `base_invalid=1` 的最终状态字，以覆盖上一帧结果并
明确通知PS当前帧未检测到有效基频。

## 十七、实现时重点检查

请重点检查以下问题：

1. 三个 `index_500` 是否分别为基频的 1、2、3 倍；
2. 中间乘法是否使用足够位宽；
3. FFT bin 换算和四舍五入是否正确；
4. 7 点窗口是否发生左右越界；
5. `mem_req` 未被 `mem_ready` 接受时是否正确保持或重新提交；
6. 同一周期提交请求并接收数据时，两个计数器是否都正确更新；
7. 第 7 个 `mem_rdata` 是否包含在最终能量中；
8. 7 点内部累加是否发生位宽溢出；
9. 三组能量是否均使用“加 4 后右移 3 位”；
10. 四舍五入加法是否先扩展一位；
11. 谐波判断是否使用缩放前的宽位能量；
12. 比例判断的乘法中间结果是否足够宽；
13. 不存在的谐波是否仍写入候选频率和实际测得能量；
14. 位置无效的候选频率是否写入能量 0；
15. `result_count` 和帧编号是否已经完全删除；
16. 两个掩码是否正确打包进地址 0；
17. 地址 7 是否固定写入 `32'd3`；
18. 地址 9 的比例参数顺序是否正确；
19. 地址 0 的最终状态字是否为整帧最后一次 BRAM 写入；
20. `done` 是否只持续一个时钟周期；
21. 新一帧开始时是否清除上一帧的所有状态和掩码；
22. 复位后所有 BRAM 写控制信号是否回到无效状态。
