
峰峰值检测模块不需要直接控制 BRAM。它只需要在一帧 65536 点处理完成后，向“测量数据汇总写入 BRAM”模块提交一次 32 位 Vpp 结果及有效脉冲。

2. 推荐输出接口
   // ============================================================================
   // 最终峰峰值结果输出
   // ============================================================================

// 一帧65536点的最终截尾平均峰峰值。
// 无符号整数，数值尺度与输入的FIR输出数据一致。
// 例如输入数据为 (adc_code - 512) << 6，则本结果也带有相同的64倍缩放。
output logic [31:0] vpp_out,

// vpp_out结果有效脉冲。
// 每处理完一帧65536个有效采样，仅拉高一个时钟周期。
// 汇总写BRAM模块应在该脉冲到来时锁存vpp_out。
output logic        vpp_valid,

// 可选状态输出：正在处理一帧数据。
// 从接受该帧第一个有效点开始拉高，产生vpp_valid后拉低。
output logic        vpp_busy,

// 可选错误脉冲。
// 检测到sample_first、sample_last或有效采样数量不匹配时拉高一拍。
output logic        vpp_error

其中真正送入“测量数据汇总写入 BRAM”模块的接口只需要：

vpp_out
vpp_valid

vpp_busy 和 vpp_error 送给顶层控制或调试逻辑，不必写入结果 BRAM。

3. 输出数据格式

当前 BRAM 汇总模块要求 Vpp 为 32 位无符号数，因此：

vpp_out[31:0]：32位无符号整数

峰峰值模块不负责换算成伏特，只输出数字码值。

假设 FIR 输出是 16 位有符号数：

最小值：-32768
最大值： 32767
最大峰峰值：65535

所以单段 Vpp 实际只需要 16 位，但最终统一零扩展到 32 位：

vpp_out <= {16'd0, trimmed_vpp};

内部位宽建议：

logic signed [15:0] segment_max;
logic signed [15:0] segment_min;

logic        [15:0] segment_vpp;

// 16 × 65535 = 1048560，需要20位
logic        [19:0] vpp_sum;

logic        [19:0] trimmed_sum;

segment_vpp =

    .clk          (clk),
    .rst          (rst),

    .vpp_in       (vpp_data),
    .vpp_valid    (vpp_data_valid),

    // 其他波形、均方值接口
    ...
);

汇总模块中处理方式为：

if (vpp_valid) begin
    vpp_latched  <= vpp_in;
    vpp_received <= 1'b1;
end

之后汇总模块在 BRAM 空闲时写入：

BRAM字地址0：Vpp，32位无符号
BRAM字地址1：均方值，32位无符号
BRAM字地址2开始：FIR波形，每两个16位采样拼成一个32位字

峰峰值模块不应输出：

bram_addr
bram_wr_en
bram_wr_data
frame_done

这些都应由汇总写 BRAM 模块统一管理。

5. vpp_valid 的时序

推荐采用独立的最终计算状态，避免最后一个分段结果因为非阻塞赋值而漏算。

第65536个有效采样到来
        │
        ▼
更新第16段最大值和最小值
        │
        ▼
计算第16段Vpp，并更新总和、两个最大值、两个最小值
        │
        ▼
计算截尾平均
        │
        ▼
vpp_out更新，vpp_valid拉高一拍

因此可以允许 vpp_valid 在最后一个 sample_valid 之后延迟约 1～2 个时钟周期。汇总模块已经采用结果锁存方式，不要求 Vpp 与波形最后一个采样同时完成。

6. 推荐的最终端口定义
   module peak_to_peak_detector #(
   parameter integer DATA_WIDTH     = 16,
   parameter integer FRAME_SIZE     = 65536,
   parameter integer SEGMENT_COUNT  = 16,
   parameter integer SEGMENT_SIZE   = 4096,
   parameter integer TRIM_COUNT     = 2
   ) (
   input  logic                         clk,
   input  logic                         rst,

   input  logic signed [DATA_WIDTH-1:0] sample_data,
   input  logic                         sample_valid,
   input  logic                         sample_first,
   input  logic                         sample_last,

   output logic [31:0]                  vpp_out,
   output logic                         vpp_valid,

   output logic                         vpp_busy,
   output logic                         vpp_error
   );

最关键的接口约定是：

vpp_out   ：一帧的最终截尾平均峰峰值，32位无符号
vpp_valid ：结果有效一拍，与vpp_out同时有效

汇总模块收到 vpp_valid 后锁存结果，写入 BRAM 字地址 0；整个系统的 frame_done 仍由汇总模块在波形、Vpp、均方值等所有启用通道完成后统一产生。
