# 功率谱计算模块设计说明

## 一、模块职责

功率谱计算模块位于 `fft_4096_wrapper` 与 `spectrol` 之间，负责把 FFT 输出的
实部和虚部转换为正频率功率谱。

当前固定处理链路为：

```text
fft_4096_wrapper
    ↓ 4096点自然顺序FFT，Re/Im均为S20
power_spectrum_calculator
    ↓ 2048点正频率功率谱，U32
spectrol
    ↓
2048×32 bit频谱BRAM
```

本模块负责：

1. 接收完整的 4096 点 FFT 输出流；
2. 计算原始功率 `Re² + Im²`；
3. 将 40 位原始功率固定右移 8 位并四舍五入；
4. 将结果限制为 32 位无符号数；
5. 只输出 FFT 下标 0～2047 的正频率功率谱；
6. 继续接收并丢弃下标 2048～4095 的负频率半区，避免堵塞 FFT；
7. 保持输入、输出的 valid-ready 握手和帧标志对齐；
8. 检查 FFT 下标及帧标志是否符合 4096 点自然顺序协议。

本模块不负责：

- FFT 运算；
- FFT 输出的 S29 到 S20 量化；
- 频谱 BRAM 地址仲裁；
- 基频检测；
- 基波和谐波的 7 点能量累加；
- 将频谱功率恢复为电压或幅值。

建议 RTL 文件名：

```text
power_spectrum_calculator.sv
```

---

## 二、固定系统参数

当前设计固定使用：

```text
FFT点数                  = 4096
FFT输出顺序              = Natural Order
FFT实部位宽              = 20 bit，S20二进制补码
FFT虚部位宽              = 20 bit，S20二进制补码
完整FFT下标              = 0～4095
保存的正频率下标         = 0～2047
原始功率位宽             = 40 bit，无符号
频谱BRAM功率位宽         = 32 bit，无符号
功率固定右移位数         = 8
处理时钟                 = 100 MHz
有效输入采样率           = 2 MSPS
```

FFT 输入采样率为 2 MHz，频率分辨率为：

\[
\Delta f=\frac{2,000,000}{4096}=488.28125\text{ Hz}
\]

频谱下标与频率的关系为：

\[
f_k=k\times488.28125\text{ Hz}
\]

## 三、上下游接口

### 3.1 上游：FFT封装模块

`fft_4096_wrapper` 提供：

```text
fft_re
fft_im
fft_bin
fft_valid
fft_ready
fft_first
fft_last
```

其中：

- `fft_re`、`fft_im` 为经过收敛舍入和饱和后的 S20；
- `fft_bin` 为自然顺序 FFT 下标 0～4095；
- `fft_first` 只与下标 0 对齐；
- `fft_last` 只与下标 4095 对齐；
- 一次输入传输成功的条件为 `fft_valid && fft_ready`。

### 3.2 下游：Spectrol

本模块向 Spectrol 提供：

```text
power_data
power_bin
power_valid
power_ready
power_first
power_last
```

其中：

- `power_data` 为缩放后的 U32 功率；
- `power_bin` 范围为 0～2047；
- `power_first` 只与 `power_bin=0` 对齐；
- `power_last` 只与 `power_bin=2047` 对齐；
- 一次输出传输成功的条件为 `power_valid && power_ready`。

现有 Spectrol 设计接口应增加：

```verilog
output power_ready;
```

在 `WRITE_SPECTRUM` 状态中：

```text
power_ready = 1
```

其他状态中：

```text
power_ready = 0
```

Spectrol 只有在成功接收 `power_last` 后，才能认为 2048 点正频率功率谱已经
完整写入频谱 BRAM。

## 四、推荐端口

```systemverilog
module power_spectrum_calculator #(
    parameter int unsigned FFT_COMPONENT_WIDTH = 20,
    parameter int unsigned RAW_POWER_WIDTH     = 40,
    parameter int unsigned POWER_WIDTH         = 32,
    parameter int unsigned POWER_SHIFT         = 8
) (
    input  wire logic               clk,
    input  wire logic               rst,
    input  wire logic               clear_error,

    // FFT输入流：完整4096点自然顺序输出
    input  wire logic signed [19:0] fft_re,
    input  wire logic signed [19:0] fft_im,
    input  wire logic        [11:0] fft_bin,
    input  wire logic               fft_valid,
    output wire logic               fft_ready,
    input  wire logic               fft_first,
    input  wire logic               fft_last,

    // 正频率功率谱输出流：下标0～2047
    output      logic        [31:0] power_data,
    output      logic        [10:0] power_bin,
    output      logic               power_valid,
    input  wire logic               power_ready,
    output      logic               power_first,
    output      logic               power_last,

    // 完成与诊断
    output      logic               fft_frame_done,
    output      logic               power_frame_done,
    output      logic               protocol_error
);
```

第一版参数固定为上述数值。若参数被改为未经验证的组合，应在 elaboration 阶段
使用断言直接报错。

## 五、功率计算

### 5.1 原始功率

对于第 \(k\) 根 FFT 谱线：

\[
P_{\text{raw}}[k]
=
\operatorname{Re}[k]^2+\operatorname{Im}[k]^2
\]

输入实部和虚部均为 20 位有符号二进制补码：

```text
-524288～+524287
```

单个平方的最大值为：

\[
(-2^{19})^2=2^{38}
\]

两个平方之和的最大值为：

\[
2^{38}+2^{38}=2^{39}
\]

因此结果需要 40 位无符号数表示：

```text
RAW_POWER_WIDTH = 40
```

注意，SystemVerilog 中两个有符号 20 位数相乘得到 40 位有符号位模式。平方结果
虽然数学上非负，后续加法仍必须显式按无符号数处理，不能让符号扩展影响结果。

推荐中间信号：

```systemverilog
logic [39:0] re_square;
logic [39:0] im_square;
logic [40:0] raw_power_ext;
```

加法前先各扩展一位：

```systemverilog
raw_power_ext =
    {1'b0, re_square} +
    {1'b0, im_square};
```

合法 S20 输入下，`raw_power_ext[40]` 应始终为 0。

### 5.2 固定缩放

为了让频谱 BRAM 和后续模块统一使用 32 位数据，定义：

\[
P_{32}[k]
=
\operatorname{round}
\left(
\frac{P_{\text{raw}}[k]}{256}
\right)
\]

硬件形式为：

```text
power32 = (raw_power + 128) >> 8
```

因为功率是非负数，加 128 后右移 8 位可以实现普通四舍五入。

舍入加法必须先扩展位宽：

```systemverilog
rounded_power_ext =
    raw_power_ext +
    41'd128;
```

不能直接在 40 位寄存器中执行 `raw_power + 128`，否则接近上界时可能丢失进位。

### 5.3 32位饱和

合法 S20 输入的最大缩放结果为：

\[
\frac{2^{39}}{2^8}=2^{31}
\]

因此正常数据能够完整放入 U32，不会发生饱和。

仍建议保留防御性饱和：

```text
缩放结果 > 0xFFFF_FFFF：
    power_data = 0xFFFF_FFFF

否则：
    power_data = 缩放结果低32位
```

该饱和逻辑用于防止未来改变输入位宽或 `POWER_SHIFT` 后静默回绕。

## 六、只输出正频率半区

实数输入的 FFT 满足共轭对称关系。当前频谱 BRAM 只保存：

```text
bin 0～2047
```

其中：

- bin 0 为直流分量；
- bin 1～2047 为正频率谱线；
- bin 2048 为 Nyquist 点，当前设计不保存；
- bin 2049～4095 为负频率对应部分，当前设计不保存。

输入成功握手时：

```text
fft_bin <= 2047：
    进入平方、求和和缩放流水线

fft_bin >= 2048：
    只推进FFT输入帧检查，不产生power_valid
```

即使已经输出 `power_last`，模块仍必须继续令 FFT 有机会发送下标 2048～4095。
不得因为正频率功率谱已经完成，就永久拉低 `fft_ready`。

---

## 七、流水线与握手

### 7.1 推荐两级流水线

推荐结构：

```text
FFT输入成功握手
    ↓
第1级：分别计算Re²和Im²，保存bin/first/last
    ↓
第2级：平方和、加128、右移8位、U32饱和并寄存输出
```

无反压时：

- 每个时钟可以接收一个 FFT 结果；
- 每个时钟可以输出一个正频率功率结果；
- 从正频率输入握手到对应输出更新经过两个寄存级；
- 下标 2048～4095 作为空泡被消费，不产生功率输出。

### 7.2 全流水线冻结

第一版推荐采用统一流水线使能：

```text
pipeline_enable = !power_valid || power_ready
fft_ready       = pipeline_enable
```

当：

```text
power_valid = 1
power_ready = 0
```

时，必须冻结：

- 两个平方结果；
- 流水级 valid；
- `power_data`；
- `power_bin`；
- `power_first`；
- `power_last`；
- 对应的内部帧信息。

这样可保证输出反压期间数据和下标不发生错位。

### 7.3 负频率半区的消费

正常情况下，Spectrol 在成功接收 bin 2047 后离开写频谱状态。此后 FFT 仍会
输出 bin 2048～4095，但这些输入不会进入功率输出流水线。

当功率输出流水线中已经没有待发送的正频率结果时：

```text
fft_ready = 1
```

从而连续消费并丢弃负频率半区。

若 bin 2047 因下游反压尚未成功输出，流水线可暂时反压 FFT；Spectrol 在收到
`power_last` 前仍处于写频谱状态，因此必须保持 `power_ready=1`。

## 八、帧标志与完成信号

### 8.1 输入帧

完整 FFT 输入必须满足：

```text
fft_bin = 0       时 fft_first = 1
fft_bin = 1～4094 时 fft_first = 0 且 fft_last = 0
fft_bin = 4095    时 fft_last = 1
```

同时要求每次成功输入的 `fft_bin` 严格按照：

```text
0, 1, 2, ... , 4095
```

推进。

### 8.2 输出帧

功率谱输出必须满足：

```text
power_bin = 0       时 power_first = 1
power_bin = 1～2046 时 power_first = 0 且 power_last = 0
power_bin = 2047    时 power_last = 1
```

### 8.3 完成脉冲

定义：

```text
power_frame_done =
    power_valid && power_ready && power_last
```

表示 2048 点正频率功率谱已经被 Spectrol 完整接收。

定义：

```text
fft_frame_done =
    fft_valid && fft_ready && fft_last
```

表示完整的 4096 点 FFT 输出，包括被丢弃的负频率半区，已经全部消费。

通常：

```text
power_frame_done 早于 fft_frame_done
```

两者不能混用：

- Spectrol 启动基频检测应依据 `power_frame_done`；
- 判断 FFT 输出通道已完全排空应依据 `fft_frame_done`。

## 九、异常处理

`protocol_error` 为粘滞错误，保持到同步复位或 `clear_error=1`。

以下情况必须置位：

1. 成功握手的 `fft_bin` 不等于内部期望下标；
2. `fft_first` 未与 bin 0 对齐；
3. `fft_last` 未与 bin 4095 对齐；
4. `fft_first` 或 `fft_last` 出现在错误位置；
5. 输入帧未完整结束又收到新的 bin 0；
6. 功率输出内部计数与流水线保存的 bin 不一致；
7. 合法输入导致原始功率出现理论上不应出现的高位溢出。

发生错误后模块仍应尽量继续消费 FFT 输出，避免数据链路死锁。顶层控制器必须
丢弃该帧频谱，并且不得启动基频检测和能量计算。

输出反压不是协议错误。只要 valid-ready 数据保持规则得到满足，等待任意多个
时钟周期都是合法行为。

## 十、与Spectrol和BRAM的连接

推荐连接：

```systemverilog
.power_data  (power_data),
.power_bin   (power_bin),
.power_valid (power_valid),
.power_ready (power_ready),
.power_first (power_first),
.power_last  (power_last)
```

Spectrol 在写频谱阶段执行：

```text
spectrum_bram_en   = power_valid && power_ready
spectrum_bram_we   = power_valid && power_ready
spectrum_bram_addr = power_bin
spectrum_bram_din  = power_data
```

频谱 BRAM 固定配置为：

```text
数据宽度：32 bit
深度：2048
逻辑地址：0～2047
数据格式：U32
```

BRAM 中保存的不是原始 40 位平方和，而是：

\[
\operatorname{round}
\left(
\frac{\operatorname{Re}^2+\operatorname{Im}^2}{256}
\right)
\]

基频检测阈值和能量计算阈值必须使用相同的 U32 功率尺度。

## 十一、能量计算缩放关系

功率模块已经完成一次固定右移：

```text
POWER_SHIFT = 8
```

后续能量计算对 7 根谱线求和时，内部累加宽度为：

```text
POWER_WIDTH      = 32
ENERGY_ACC_WIDTH = POWER_WIDTH + 3 = 35
```

为了保证任意 7 个合法 U32 功率值相加后仍能无溢出地输出 U32，能量模块固定
采用：

```text
ENERGY_SHIFT = 3
```

能量输出使用：

```text
energy_out = (energy_raw + 4) >> 3
```

功率模块和能量模块的总固定缩放为：

```text
POWER_SHIFT  = 8
ENERGY_SHIFT = 3
总右移位数  = 11
```

谐波与基波的能量比例不受该统一缩放影响。绝对能量阈值和 PS 端标定公式必须
使用总右移 11 位后的数值尺度。

## 十二、资源与时序预期

主要硬件资源包括：

- 两个 20×20 有符号平方运算；
- 一个 41 位无符号加法器；
- 一个常数 128 加法；
- 固定右移布线；
- 两级流水寄存器；
- 少量计数器和协议检查逻辑。

建议为两个平方运算添加 DSP 推断属性，但最终 DSP48 数量必须以综合报告为准。
由于 7 系列 DSP48E1 的乘法器输入宽度并非对称的 20×20，一个平方运算可能需要
不止一个 DSP48E1，不能在设计文档中预先假定总共只使用两个 DSP。

目标时钟为 100 MHz。完成 RTL 后必须执行：

```text
OOC综合
report_utilization
report_timing_summary
check_timing
```

## 十三、仿真计划

必须编写自检式 testbench，并至少覆盖：

1. 全零实部和虚部；
2. 只有实部；
3. 只有虚部；
4. 正负输入平方结果相同；
5. `fft_re=-524288`、`fft_im=-524288` 的最大功率；
6. `fft_re=+524287`、`fft_im=+524287` 的正最大值；
7. 原始功率低于、等于和高于舍入半值 128；
8. 检查 `(raw_power+128)>>8`；
9. 4096 个连续输入；
10. 输入带空拍；
11. `power_ready` 随机拉低；
12. 输出反压时数据、bin、first和last保持不变；
13. bin 0～2047 恰好输出 2048 点；
14. bin 2048～4095 不产生 `power_valid`；
15. 负频率半区仍能被完整消费；
16. `power_last` 与 bin 2047 对齐；
17. `fft_frame_done` 与 bin 4095 对齐；
18. `fft_first` 提前、缺失和重复；
19. `fft_last` 提前和缺失；
20. `fft_bin` 跳变、重复或乱序；
21. 空闲状态复位；
22. 处理中复位；
23. `clear_error` 清除粘滞错误；
24. 使用 64 位软件参考模型随机比较至少数千组输入。

参考模型计算应使用足够宽的有符号整数接收输入，再转换为无符号平方和：

```text
re64       = sign_extend(fft_re)
im64       = sign_extend(fft_im)
raw64      = re64×re64 + im64×im64
expected32 = (raw64 + 128) >> 8
```

测试结束必须明确打印：

```text
TEST PASSED
```

任何断言失败必须使仿真以失败状态结束。
