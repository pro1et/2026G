# 基频检测模块设计参考

## 1. 模块功能

基频检测模块用于从功率谱 BRAM 中找出未知周期信号的基频。

当前系统条件为：

* FFT 输入采样率：2 MHz；
* FFT 点数：4096；
* 频率分辨率：

[
\Delta f=\frac{2,000,000}{4096}=488.28125\text{ Hz}
]

* 基频不低于 10 kHz；
* 信号频率为 500 Hz 的整数倍；
* 基频定义为频谱中实际存在的最低可信频率分量；
* FFT 前使用 Hann 窗；
* 功率谱已经由前级计算：

[
P[k]=\operatorname{Re}^2[k]+\operatorname{Im}^2[k]
]

功率计算模块已经对原始功率完成固定缩放、四舍五入和 32 位处理。频谱 BRAM
中的每根功率谱线均为 32 位无符号数，本模块固定使用：

```verilog
parameter POWER_WIDTH  = 32;
parameter ENERGY_WIDTH = POWER_WIDTH + 3;  // 7点累加，共35位
```

例如频谱中存在：

[
20\text{ kHz},40\text{ kHz},60\text{ kHz}
]

则基频判定为：

[
f_0=20\text{ kHz}
]

不推测频谱中不存在的 10 kHz 分量。

---

## 2. 推荐检测思路

不建议对每一个 500 Hz 候选频率反复随机读取 7 根谱线。

更适合当前 BRAM 结构的方法是：

1. 从最低有效 FFT 谱线开始顺序读取功率谱；
2. 使用滑动窗口计算每个位置附近的 7 点累计能量；
3. 从低频向高频寻找第一个可信局部峰；
4. 将峰值谱线位置换算为最接近的 500 Hz 频率编号；
5. 可选地检查二次、三次谐波位置；
6. 输出基频编号。

整体流程为：

```text
功率谱BRAM
    ↓ 顺序读取
7点滑动能量计算
    ↓
局部峰检测
    ↓
阈值与显著性判断
    ↓
换算为500 Hz频率编号
    ↓
可选谐波验证
    ↓
输出基频
```

顺序读取可以充分利用 BRAM 流水线。即使 BRAM 读延迟为两拍，完成初始延迟后仍然可以每拍返回一根谱线。

---

## 3. 扫描范围

最低基频为 10 kHz，对应的理论 FFT 位置为：

[
\frac{10,000}{488.28125}=20.48
]

因此扫描可以从第 17 根或第 18 根谱线开始，以保证能够形成中心位于约第 20 根谱线的 7 点窗口。

建议参数化：

```verilog
parameter MIN_SCAN_BIN = 17;
parameter MAX_SCAN_BIN = 2044;
parameter HALF_WINDOW  = 3;
```

如果只分析指定频段，应将 `MAX_SCAN_BIN` 设置为对应频率上限，减少检测时间并避免高频无关噪声。

---

## 4. 7点滑动能量

对于中心谱线 (k)，定义邻域能量：

[
E[k]
====

\sum_{r=-3}^{3}P[k+r]
]

即：

[
E[k]
====

P[k-3]+P[k-2]+P[k-1]+P[k]
+P[k+1]+P[k+2]+P[k+3]
]

第一次形成完整窗口时，需要累加 7 个数据。

之后窗口每向前移动一根谱线，可以递推：

[
E[k+1]
======

E[k]-P[k-3]+P[k+4]
]

因此每拍只需要：

* 减去离开窗口的数据；
* 加入新进入窗口的数据。

不需要对每个中心位置重新进行 7 次 BRAM 读取。

---

## 5. 滑动窗口寄存器

模块内部保存最近读取的 7 根功率数据：

```verilog
reg [POWER_WIDTH-1:0] power_d0;
reg [POWER_WIDTH-1:0] power_d1;
reg [POWER_WIDTH-1:0] power_d2;
reg [POWER_WIDTH-1:0] power_d3;
reg [POWER_WIDTH-1:0] power_d4;
reg [POWER_WIDTH-1:0] power_d5;
reg [POWER_WIDTH-1:0] power_d6;
```

每收到一个有效 BRAM 数据：

```verilog
power_d0 <= power_d1;
power_d1 <= power_d2;
power_d2 <= power_d3;
power_d3 <= power_d4;
power_d4 <= power_d5;
power_d5 <= power_d6;
power_d6 <= mem_rdata;
```

窗口填满后，`power_d3` 对应窗口中心。

也可以使用寄存器数组，但为了兼容普通 Verilog `.v` 并方便综合调试，第一版使用独立寄存器更直观。

---

## 6. 邻域能量位宽

假设单根功率谱数据宽度为 `POWER_WIDTH`。

累计 7 根谱线至少需要额外 3 位：

[
\left\lceil\log_2 7\right\rceil=3
]

建议：

```verilog
localparam ENERGY_WIDTH = POWER_WIDTH + 3;
```

滑动能量寄存器：

```verilog
reg [ENERGY_WIDTH-1:0] window_energy;
```

功率和能量均为非负值，建议使用无符号数。

---

## 7. 局部峰检测

为了避免将频谱泄漏的上升沿误判为基频，需要比较连续三个中心位置的邻域能量：

[
E[k-1],E[k],E[k+1]
]

局部峰条件为：

[
E[k]>E[k-1]
]

并且：

[
E[k]\geq E[k+1]
]

内部保存：

```verilog
reg [ENERGY_WIDTH-1:0] energy_prev;
reg [ENERGY_WIDTH-1:0] energy_curr;
reg [ENERGY_WIDTH-1:0] energy_next;
```

收到新的窗口能量后移动：

```verilog
energy_prev <= energy_curr;
energy_curr <= energy_next;
energy_next <= new_window_energy;
```

当三个值都有效时，判断中间的 `energy_curr`。

对应的中心谱线地址也需要同步延迟，确保峰值能量与谱线下标对应。

---

## 8. 阈值判断

局部峰还必须超过检测阈值：

[
E[k]>T
]

第一版建议由外部输入阈值：

```verilog
input [ENERGY_WIDTH-1:0] detect_threshold;
```

这样可以在仿真和上板测试阶段灵活调整，不必重新综合。

完整的基础判断条件为：

```text
当前窗口能量超过阈值
并且
当前窗口能量大于前一个窗口
并且
当前窗口能量不小于后一个窗口
```

即：

```verilog
peak_detected =
    (energy_curr > detect_threshold) &&
    (energy_curr > energy_prev)      &&
    (energy_curr >= energy_next);
```

---

## 9. 建议增加峰值显著性判断

仅使用绝对阈值可能将缓慢变化的噪声或旁瓣误认为峰值。

可以增加简单显著性条件：

[
E[k] > E[k-1] + T_{\text{prom}}
]

或者：

[
E[k] > E[k+1] + T_{\text{prom}}
]

第一版可以采用：

```verilog
input [ENERGY_WIDTH-1:0] prominence_threshold;
```

候选峰条件可写为：

```verilog
peak_detected =
    (energy_curr > detect_threshold) &&
    (energy_curr > energy_prev)      &&
    (energy_curr >= energy_next)     &&
    ((energy_curr - energy_prev) > prominence_threshold);
```

显著性判断是否启用，可以做成参数或输入配置。

---

## 10. 基频谱线位置

找到第一个可信局部峰后，保存其中心谱线：

```verilog
base_bin <= peak_bin;
```

例如：

```text
base_bin = 1024
```

对应频率近似为：

[
1024\times488.28125\text{ Hz}=500\text{ kHz}
]

但 `base_bin` 只是 FFT 中的整数位置，不能直接作为后级谐波位置计算的唯一依据。

---

## 11. 换算为500 Hz频率编号

后级能量计算模块需要的是：

[
m_0=\frac{f_0}{500}
]

称为 `base_index_500`。

由 FFT 谱线位置 (k) 反算：

[
m_0
\approx
\operatorname{round}
\left(
\frac{k\Delta f}{500}
\right)
]

代入当前参数：

[
m_0
===

\operatorname{round}
\left(
\frac{125k}{128}
\right)
]

由于 128 是 (2^7)，硬件中可以直接使用移位：

[
m_0=
\left\lfloor
\frac{125k+64}{128}
\right\rfloor
]

Verilog 表达方式：

```verilog
wire [18:0] base_index_numerator;

assign base_index_numerator = base_bin * 16'd125 + 16'd64;
assign base_index_500       = base_index_numerator >> 7;
```

例如检测到第 41 根谱线：

[
m_0
===

\operatorname{round}
\left(
\frac{125\times41}{128}
\right)
=40
]

因此：

[
f_0=40\times500=20\text{ kHz}
]

---

## 12. 频率编号校准

为了提高稳定性，可以在初步计算出 `base_index_500` 后，检查相邻三个候选：

[
m_0-1,\quad m_0,\quad m_0+1
]

分别计算它们对应的理论 FFT 位置：

[
k(m)=
\operatorname{round}
\left(
\frac{128m}{125}
\right)
]

然后选择邻域能量最大的一个。

这一步可以补偿噪声导致的峰值中心偏移，但会增加少量随机读取。

第一版可以暂不实现，先采用：

```text
局部峰谱线
→ 换算为最近的500 Hz编号
```

待仿真发现相邻 500 Hz 误判时，再加入三候选校准。

---

## 13. 可选的谐波验证

找到最低可信峰后，可以检查它的二次或三次谐波，以提高可信度。

设检测得到：

[
m_0=base_index_500
]

第 (h) 次谐波编号为：

[
m_h=hm_0
]

对应 FFT 谱线为：

[
k_h=
\operatorname{round}
\left(
\frac{128m_h}{125}
\right)
]

硬件形式：

[
k_h=
\left\lfloor
\frac{128m_h+62}{125}
\right\rfloor
]

可以检查：

[
2f_0,\quad3f_0
]

附近是否存在足够能量。

但谐波验证不能作为绝对必要条件，因为输入信号可能是接近纯正弦的信号，只有基频而没有明显谐波。

推荐判定规则：

```text
基频峰很强：
    直接接受

基频峰只超过普通阈值：
    至少一个整数倍位置也超过阈值时接受
```

第一版也可以先不做谐波验证，只实现最低可信局部峰检测。

---

## 14. 与频谱控制器的接口

基频检测模块不直接连接 BRAM。

它通过统一的请求—响应接口读取功率谱：

```verilog
output reg                   mem_req;
output reg  [10:0]           mem_addr;
input                        mem_ready;
input                        mem_rvalid;
input       [POWER_WIDTH-1:0] mem_rdata;
```

接口含义：

* `mem_req`：本周期提交一个读请求；
* `mem_addr`：待读取的功率谱地址；
* `mem_ready`：控制器本周期能够接受请求；
* `mem_rvalid`：返回数据有效；
* `mem_rdata`：返回的功率谱数据。

只要：

```verilog
mem_req && mem_ready
```

该地址就成功提交。

基频检测模块必须只在：

```verilog
mem_rvalid == 1'b1
```

时处理 `mem_rdata`。

---

## 15. 推荐模块接口

采用 Verilog-2001：

```verilog
module base_detector #(
    parameter POWER_WIDTH  = 32,
    parameter ENERGY_WIDTH = 35,
    parameter MIN_SCAN_BIN = 17,
    parameter MAX_SCAN_BIN = 2044
)(
    // 时钟与复位
    input                         clk,
    input                         rst,

    // 控制接口
    input                         start,
    input      [ENERGY_WIDTH-1:0] detect_threshold,
    input      [ENERGY_WIDTH-1:0] prominence_threshold,

    // 频谱BRAM读取接口
    output reg                    mem_req,
    output reg [10:0]             mem_addr,
    input                         mem_ready,
    input                         mem_rvalid,
    input      [POWER_WIDTH-1:0]  mem_rdata,

    // 检测结果
    output reg                    base_valid,
    output reg                    base_done,
    output reg [15:0]             base_index_500,
    output reg [10:0]             base_bin,
    output reg [ENERGY_WIDTH-1:0] base_energy
);
```

其中：

* `base_valid` 表示成功检测到基频；
* `base_done` 为检测完成脉冲；
* `base_index_500` 为基频的 500 Hz 编号；
* `base_bin` 为对应的整数 FFT 谱线；
* `base_energy` 为基频邻域累计能量，可用于调试和可信度判断。

---

## 16. 提供给能量计算模块的数据

基频检测模块完成后，核心输出为：

```verilog
base_valid;
base_index_500;
```

例如检测到 20 kHz：

```text
base_index_500 = 40
base_valid     = 1
```

能量计算模块内部计算：

[
m_h=h\times base_index_500
]

再计算：

[
k_h=
\operatorname{round}
\left(
\frac{128m_h}{125}
\right)
]

不能只传递 `base_bin` 后直接计算：

[
k_h=h\times base_bin
]

因为整数谱线位置已经发生过一次取整，高次谐波会产生累计位置误差。

## 17. 推荐状态机

使用 `localparam` 定义状态，不使用 SystemVerilog 的 `enum`。

```verilog
localparam STATE_IDLE       = 4'd0;
localparam STATE_READ       = 4'd1;
localparam STATE_FILL       = 4'd2;
localparam STATE_SCAN       = 4'd3;
localparam STATE_CONVERT    = 4'd4;
localparam STATE_VERIFY     = 4'd5;
localparam STATE_DONE       = 4'd6;
localparam STATE_NOT_FOUND  = 4'd7;
```

### `STATE_IDLE`

等待 `start`，清除上一帧状态。

### `STATE_READ`

从 `MIN_SCAN_BIN` 开始连续发送 BRAM 读地址。

### `STATE_FILL`

等待滑动窗口填满 7 个有效数据。

也可以与 `STATE_READ` 合并，通过有效数据计数器判断窗口是否填满。

### `STATE_SCAN`

每收到一根新谱线：

1. 更新滑动窗口；
2. 更新邻域能量；
3. 更新前、当前、后能量；
4. 判断中间位置是否为可信局部峰。

### `STATE_CONVERT`

保存检测到的 `base_bin`，计算：

[
base_index_500
==============

\frac{125base_bin+64}{128}
]

### `STATE_VERIFY`

可选地检查二次、三次谐波。

第一版可直接跳过。

### `STATE_DONE`

输出：

```verilog
base_valid <= 1'b1;
base_done  <= 1'b1;
```

### `STATE_NOT_FOUND`

扫描结束仍未检测到基频：

```verilog
base_valid <= 1'b0;
base_done  <= 1'b1;
```

## 18. 地址与数据的同步

BRAM 存在固定读延迟，因此谱线地址和返回数据不能直接使用同一个计数器表示。

建议分别维护：

```verilog
reg [10:0] issue_addr;
reg [10:0] receive_addr;
```

或者让频谱控制器在返回数据时同时返回对应地址：

```verilog
input [10:0] mem_raddr;
```

若控制器不返回地址，则基频检测模块需要将成功提交的地址按照 BRAM 延迟进行移位。

由于当前读取是严格连续的，也可以在每次 `mem_rvalid` 时递增 `receive_addr`：

```verilog
if (mem_rvalid)
    receive_addr <= receive_addr + 1'b1;
```

需要保证扫描阶段不会丢失请求或插入额外地址。

---

## 19. 异常与边界处理

### 未检测到基频

扫描到 `MAX_SCAN_BIN` 后仍无有效峰：

```verilog
base_valid <= 1'b0;
base_done  <= 1'b1;
```

### 地址越界

7 点窗口要求：

[
k-3\geq0
]

[
k+3\leq2047
]

扫描起止地址应留出窗口边界。

### 累加溢出

必须检查：

* 单根功率位宽；
* 7 点能量位宽；
* 滑动减法是否出现无符号下溢；
* 阈值数据位宽是否一致。

理论上：

[
E[k]-P[k-3]+P[k+4]
]

不会为负，但固定点实现时建议先加新数据再减旧数据，或增加一位中间位宽。

### 连续帧

每次 `start` 时清除：

* 滑动窗口；
* 窗口填充计数；
* 能量寄存器；
* 地址计数器；
* `base_valid`；
* `base_done`；
* 上一帧基频结果。

---

## 20. 第一版推荐范围

第一版建议只实现：

1. 顺序读取功率谱；
2. 7 点滑动能量；
3. 固定外部阈值；
4. 局部峰检测；
5. 从低频向高频寻找第一个可信峰；
6. 将峰值谱线换算为 500 Hz 编号；
7. 输出 `base_index_500`、`base_bin` 和 `base_energy`；
8. 未检测到时输出无效状态。

第一版暂不实现：

* 自动噪声估计；
* 复杂谐波评分；
* 多峰排序；
* 抛物线插值；
* 频谱模板匹配；
* 自动阈值调整；
* 多帧平均。

---

## 21. 最终数据关系

基频检测模块输出：

```text
base_index_500
base_bin
base_energy
base_valid
```

其中：

[
f_0=500\times base_index_500
]

谐波能量模块接收：

```text
base_index_500
base_valid
```

并生成各次谐波位置。

最终写入结果 BRAM 的每条记录可以采用：

```text
16位频点位置 + 能量
```

其中频点位置为 FFT 整数谱线编号，例如：

```text
1024 → 500 kHz
```

基频检测模块与能量计算模块之间则以 `base_index_500` 作为主要频率参数，避免高次谐波的谱线位置累计误差。
